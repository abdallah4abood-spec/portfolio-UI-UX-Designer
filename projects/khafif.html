Overview

Khafif is a portfolio project in development: a lightweight, Arabic-first e-commerce mobile app built for low-bandwidth conditions. The catalog is demonstration data and payments are test payments. No real customers, payments or inventory are involved.

My contributions

  • Mobile app structure with Expo Router navigation and tabs
  • Arabic and English translations with RTL support
  • Offline banner
  • Medusa v2 backend running in Docker with PostgreSQL

Current status

  • Completed: Medusa backend running; demo catalog of 16 products; backend purchase flow through cart, shipping, test payment and order creation.
  • Current: mobile navigation and tabs, Arabic and English translations, RTL support, offline banner. At the last status report, 26 Jest tests passed and TypeScript and lint checks were clean.
  • Not finished: the mobile application as a whole.

What this page does not claim

  • Design goals are Arabic-first use, low-bandwidth awareness, offline-friendly behavior, a clear shopping flow and efficient data use. These are goals, and not all are claimed as fully achieved.
  • It is not a finished or production product.
