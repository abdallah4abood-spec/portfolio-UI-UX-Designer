A practical process

Clarity before polish.

My general approach, adapted to the project—not a retroactive claim that every project followed an identical process.

  1. Frame

    Clarify the audience, product context, constraints, and the decision the experience needs to support.

  2. Structure

    Organize content, map the core flow, and make states visible before drawing final screens.

  3. Design

    Build hierarchy, reusable components, responsive behavior, and a coherent visual language.

  4. Build

    Translate the system into semantic, responsive code without losing the intent of the design.

  5. Verify

    Check keyboard use, content edge cases, breakpoints, themes, and implementation fidelity.
