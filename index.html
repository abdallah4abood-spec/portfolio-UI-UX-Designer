How I work

My general approach to building a digital product, not a record of every step on every project.

  1. Understand

    Learn the product context, the requirements and the problem.

  2. Structure

    Organize information, define the interface structure and plan user flows.

  3. Design

    Develop layouts, visual hierarchy, reusable components and design decisions.

  4. Build

    Translate the interface into responsive, accessible frontend code.

  5. Refine

    Review the experience, improve details and check the implementation.
